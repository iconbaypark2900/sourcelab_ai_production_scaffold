## SourceLab Library Builder v1

Use the CLI library pipeline to grow curated packs from local docs and metadata-only collectors (arXiv, PubMed, NVD). Promotion is dry-run by default; use `--force` to write into `data/source_packs/<pack>/sources/`. When lesson runs have thin evidence, check `artifacts/runs/<run_id>/source_expansion_suggestions.json` for collector hints aligned to the run topic.

```bash
sourcelab library collect-local --path . --domain user_project_library
sourcelab library stats
sourcelab library promote --domain user_project_library --target-pack agentic_engineering_v1 --dry-run
```

## Adaptive Research Loop v1

Recommended follow-up workflow for the three domain packs above:

1. `sourcelab lesson create --topic "<topic>" --source-pack <pack> --difficulty 2`
2. `sourcelab answer submit --run latest --answer "..."`
3. Repeat lesson create with the same topic — the follow-up plan uses the topic profile
4. `sourcelab research evolution --run latest` — compare coverage/genericness/gaps vs prior runs
5. `sourcelab research expansion --run latest` — library collector commands when evidence is thin
6. `sourcelab research expansion run --run latest --dry-run` — preview collector execution
7. `sourcelab research expansion run --run latest --execute` — run supported collectors (when network/local conditions allow)
8. `sourcelab research expansion promote --run latest --dry-run` — propose source pack promotions
9. `sourcelab research expansion promote --run latest --force` — write promoted sources (only when safe)
10. Rerun lesson create, then `sourcelab research gap-closure --run latest` — honest improvement verdict

Example (quantum finance):

```bash
sourcelab lesson create --topic "quantum hybrid portfolio optimizer" --source-pack quantum_finance_v1 --difficulty 2
sourcelab answer submit --run latest --answer "A quantum hybrid portfolio optimizer should define the objective..."
sourcelab lesson create --topic "quantum hybrid portfolio optimizer" --source-pack quantum_finance_v1 --difficulty 2
sourcelab research evolution --run latest
sourcelab research expansion --run latest
sourcelab research expansion run --run latest --dry-run
sourcelab research expansion promote --run latest --dry-run
sourcelab lesson create --topic "quantum hybrid portfolio optimizer" --source-pack quantum_finance_v1 --difficulty 2
sourcelab research gap-closure --run latest
```

## Guided Gap Closure Orchestration v1.1

Orchestrate the full loop from a weak baseline run (defaults: dry-run expansion/promotion; no manifest repair; no follow-up creation):

```bash
sourcelab research gap-closure run --run latest --dry-run
sourcelab research expansion run --run latest --dry-run
sourcelab research expansion promote --run latest --dry-run
sourcelab research gap-closure run --run latest --execute --promote-force --repair-manifests --create-followup --difficulty 2
```

Writes `gap_closure_orchestration.json` with steps, commands, promotion/manifest status, follow-up lesson command, and optional gap-closure verdict. Manifest repair runs only after `--promote-force`.

## Adaptive Research Loop v1.2 — Answer-Submit Bridge + Orchestration Replay

Bridge a learner answer into orchestration before expansion; replay planned steps from artifacts; track multi-hop evolution via `followup_run_id`:

```bash
sourcelab research gap-closure run --run latest --dry-run --answer-text "A strong answer should define the objective, evidence, risks, and validation path."
sourcelab research gap-closure run --run latest --execute --answer-file path/to/answer.md
sourcelab research gap-closure replay --run latest
sourcelab research gap-closure replay --run latest --continue
```

Topic profiles gain optional `orchestration_runs`, `followup_chain`, and `last_gap_closure_verdict` fields applied on orchestration completion.

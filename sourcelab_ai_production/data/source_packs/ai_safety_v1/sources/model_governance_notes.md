# Model Governance Notes

## Governance Scope

Model governance covers approval workflows, access controls, documentation of intended use, change management, and audit trails for prompts, datasets, and deployment configurations.

## Key Controls

Require model cards, version pinning, rollback plans, and separation between experimentation and production. Define owners for each model route and enforce review before enabling new capabilities.

## Accountability

Governance is not optional for high-impact deployments. Teams should record decisions, evidence from evals, and residual risk accepted at launch.
